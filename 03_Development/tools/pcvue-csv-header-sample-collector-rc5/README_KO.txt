PCVue CSV Limited Header Discovery Collector RC5

이 도구는 승인된 CSV 11개만 대상으로 합니다.
VAREXP는 파일당 최대 3 logical records 또는 64 KiB 중 먼저 도달하는 한도에서 schema header를 탐색합니다.
PvTrend CSV는 첫 logical record만 검증합니다.
HISTO content parser는 구현하지 않았으며 MANUAL_FORMAT_REVIEW_REQUIRED로 유지합니다.

비schema record, preamble field, data row는 결과 또는 로그에 저장하지 않습니다.
DAT, XLSX, XML 및 승인 목록 밖 파일 content에 접근하지 않습니다.
Network, DB, PLC, OPC 접근이나 서비스/프로세스 제어를 수행하지 않습니다.
원본 파일을 생성, 변경, 삭제하지 않습니다.
