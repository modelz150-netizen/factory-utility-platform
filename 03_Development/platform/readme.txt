Plugin-owned authenticated Factory Utility Platform application foundation.

== Description ==

Provides the approved /factory-utility/ application route, WordPress capability
boundary, admin launcher, multilingual Home Dashboard fixture for non-production
review, and production fail-closed behavior.

No real operational source, alarm source, KPI source, AI, database schema,
workflow, notification, or control integration is included.

== Installation ==

Install and activate the versioned plugin ZIP in a development or staging
WordPress environment. Explicitly grant view_factory_utility_dashboard to the
review account. Production deployment is not authorized by this package.
