# Project Definition

| Field | Value |
|---|---|
| Name | Factory Utility Platform |
| Product type | Production engineering platform |
| Primary users | Semiconductor and industrial utility engineers |
| Current phase | Sprint 1 - Foundation |
| Primary platform | WordPress |
| Core technologies | PHP, JavaScript, CSS |

## Mission

Build a dependable, maintainable engineering platform that helps utility engineers calculate, reference, diagnose, monitor, and improve industrial utility systems. The product is an operational engineering platform, not a content-only blog.

## Product Scope

- Home Dashboard
- Engineering Calculator
- Engineering Reference
- Trouble Guide
- Equipment Library
- Vendor Library
- AI Copilot
- SCADA Dashboard
- Energy and Carbon Management

## Current Sprint

Sprint 1 establishes the shared foundation for:

- Project architecture
- Dashboard framework
- Calculator framework
- Reference framework
- Design system
- Documentation system

## Success Principles

- Engineers can trust calculations and trace their sources.
- Common capabilities are reusable across modules.
- Mobile use is a primary scenario, not an adaptation.
- Performance, SEO, accessibility, and security are designed in from the beginning.
- The system can evolve without duplicating business logic or presentation components.

## Out of Scope for Sprint 1

- Production SCADA integrations
- Production AI Copilot operations
- Final commercial vendor marketplace workflows
- Large-scale data migration
- Unapproved third-party service commitments

These areas may be researched or architected, but implementation requires backlog prioritization and user approval.
