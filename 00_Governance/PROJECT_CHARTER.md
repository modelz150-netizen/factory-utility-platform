# Factory Utility Platform

## Mission

Build a production-quality engineering platform for semiconductor and industrial utility engineers. The product is a long-term engineering workspace and operational platform, not a blog.

## Product Scope

- Home Dashboard
- Engineering Calculator
- Engineering Reference
- Trouble Guide
- Equipment Library
- Vendor Library
- AI Copilot
- SCADA Dashboard
- Energy & Carbon Management

## Architecture Principles

- WordPress first
- PHP, JavaScript, and CSS
- Modular architecture
- Mobile first
- SEO first
- Performance first
- Reusable components
- Long-term maintainability
- No duplicate functionality

## Definition of Engineering Quality

Every feature must provide clean architecture, documentation, responsive behavior, error handling, and a credible path for future extension. Important design decisions and their tradeoffs must be recorded.
