# Governance Templates

This directory contains reusable templates governed by `../standards/DOCUMENT_STANDARD.md`. Templates improve consistency but do not replace engineering judgment or the acceptance criteria of the relevant work item.

Initial templates:

- `ADR_TEMPLATE.md` for durable architecture decisions
- `DOCUMENT_TEMPLATE.md` for normative Governance documents

Future templates require a clear owner, intended artifact location, lifecycle, and validation rules.
